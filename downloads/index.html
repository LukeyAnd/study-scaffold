What the agent will ask

It inspects your material first, then asks only what is missing: what is covered, what the exam requires, when it happens, how much time you have, and where you need help. It uses ask widgets when available or ordinary chat.

For Codex, extract the skill folder into ~/.agents/skills/ and invoke $exam-review-designer. Other hosts may have a different skill-import flow. The optional builder needs Python 3.10+; the finished browser review does not.
