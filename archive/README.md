# Historical input

`midterm_trainer.html` is the original supplied prototype, retained for provenance. Start the current app with the repository root's `index.html`; the historical file has its own older behavior and storage.

`archive/extract-bank.cjs` is a one-time adapter for this input, not a normal build step. It requires `--output NEW_FILE.js` and refuses to overwrite existing files. Use it only when deliberately regenerating and reviewing that legacy content. The tax example is unverified course material.
